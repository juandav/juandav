## 🛰️ Mission Briefing

I'm an **AI Engineer** with **10+ years of experience** building software, from full-stack platforms and cloud-native backends to **event-driven systems**, **real-time streaming** and, today, **AI-powered products**.

I believe the real job isn't writing code, it's **solving problems**. Code is just the vehicle. But a good solution needs real understanding, so before I build in a new domain I go deep and learn it properly. That's how I make engineering decisions I can stand behind.

I'm passionate about programming as a craft. I still enjoy writing **handcrafted code** line by line, and I also build **AI-guided**. Knowing when to use each is part of the job.

## 🌌 Flight Principles

> **01 · Solve the problem, not the ticket.** Understand the *why* before writing the *how*.
>
> **02 · Master the domain first.** Real expertise beats guesswork, so I learn deeply before I build.
>
> **03 · Simple scales.** Clean architecture and maintainable code outlast clever hacks.
>
> **04 · Measure, then optimize.** Performance is a feature, but only when it's driven by data.
>
> **05 · Craft meets copilot.** Handcrafted code where precision matters, AI-guided where speed matters.
